# 🎮 Steam Analytics

Data analysis project focused on the most popular games on Steam.

## 📊 About the Project

Steam Analytics is a personal data analysis project created to explore,
organize and visualize information about the Top 20 games on Steam.

The project combines data collection, data organization, SQL queries
and Power BI dashboards to transform raw data into useful insights.

## 🛠️ Technologies

- SQL
- MySQL
- Power BI
- Excel
- Git & GitHub
